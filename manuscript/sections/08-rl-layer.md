# 7. Reinforcement Learning Optimization Layer

The RL layer is the planning organ of the MAPE-K loop (Figures 9–10). Its formulation is deliberately small and frozen: a 30-state space (state-v1.5: workload class {agg, join, rdd_sort, skew_join, mixed} × size bin {S, M, L} × feedback bin {le0, gt0}), where the size bin comes from dataset manifests recorded before any run — never from live measurement — and missing history maps to the pessimistic `le0` bin by documented convention [3][4]. The 15-state context-only variant (v1) and the 2-state feedback-only variant (v2) exist for the A1/A2 ablations. Continuous telemetry (shuffle, spill, CV, CPU) is collected after execution for reward computation and is never part of the tabular state.

Actions form a 12-cell grid: shuffle partitions {16, 32, 64, 128} × execution parallelism {local-2, local-4, local-8}, with a 4-action structural subset ({0,3,6,9}) for the A4 granularity ablation. Reward is the frozen R3 formula — Equation (1) — combining normalized time improvement against a calibrated T_ref, task-balance, and spill waste, with failure scoring exactly −1:

R(s,a) = 1.0·clip((T_ref − T)/T_ref, −1, +1) + 0.2·(1 − min(1, CV/0.5)) − 0.2·min(1, spill/0.10) − 1.0·1[fail]   (1)

Learning is ε-greedy tabular Q-learning (α = 0.2, γ = 0.0 bandit mode, ε 1.0 → 0.05 at 0.95/episode) with the standard update [3][4]:

Q(s,a) ← Q(s,a) + α·[r − Q(s,a)]   (2)

ε_e = max(0.05, 1.0·0.95^e)   (3) Offline initialization (Q0) seeds every table entry from the median EXP-002 outcomes before the first online episode, so learning starts informed rather than blank; training then proceeds in epochs (full passes over the cell cycle) with checkpoints every 25 episodes and early stopping after 2 stable epochs. Failed episodes update the table at r = −1 rather than being skipped — the mechanism by which the agent learns to avoid pathological configurations.

Offline initialization deserves detail because it carries much of the sample efficiency. Q0 is built exclusively from authorized EXP-002 TRAIN records: per (state, action) cell, the median realized reward becomes the initial Q-value, with evidence-free pairs set optimistically to 0.5 to encourage visitation. Aggregation is median-based (the project's primary statistic), provenance records which grid observations back each entry, and the init is keyed to state-v1.5 keys — which is also why a hypothetical multi-step schema would not inherit it. Bandit mode (γ = 0.0) is the frozen default, not a simplification of convenience: with single-decision episodes the bootstrapping target never activates (0 of 232 recorded training executions ever reached it), and enabling γ = 0.9 would require a non-terminal environment path, per-phase metrics and calibrations, and a new state schema — a build, not a flag, correctly gated NO with five written reopen conditions. The training loop runs epochs defined as full passes over the planned cell cycle, checkpointing every 25 episodes with early stopping after two stable epochs — documented explicitly as a budget-saving heuristic, never as convergence evidence, a distinction three project audits enforce so the stopping rule cannot be misread as a learning claim.
